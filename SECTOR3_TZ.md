# ТЗ: Сектор 3 — 5 планет с механикой иллюзий

## Контекст

Игра уже содержит 2 сектора по 5 планет. Каждый сектор требует завоевания всех 5 предыдущих планет для разблокировки. В Секторе 2 введена механика щита (QTE-кольцо). Сектор 3 вводит новую боевую механику — **иллюзия** — с обратными последствиями за провал QTE: вместо штрафа ко времени противник восстанавливает здоровье.

## 5. Логика боя (BattleScreen.tsx)

### 5.1 Цикл иллюзии

По аналогии с shield-циклом:
- `intervalMs` — противник виден, урон наносится нормально
- `durationMs` — иллюзия активна (визуальный эффект: противник "раздваивается" / полупрозрачный)

### 5.2 QTE при активной иллюзии

- Пока иллюзия активна и QTE не было попытки → показывать SkillCheckRing
- `handleQteSuccess()`: иллюзия рассеивается раньше времени → окно усиленной атаки (×2 урона, по аналогии со щитом)
- `handleQteFail()`:
  1. Флаг `qteAttempted = true`, `qteFailed = true`
  2. Вызвать `healBattle(0.10)` — противник восстанавливает 10% от `maxHP` (не более `maxHP`)

### 5.3 Режим иллюзии после провала QTE

Если `illusion.active && illusion.qteFailed`:
- Атаки игрока **не наносят урон** (корабль бьёт "клон")
- Каждый клик → вызов `healBattle(0.05)` — противник получает +5% от `maxHP` (не более `maxHP`)
- Визуальный фидбек: анимация "промах" или зелёное число "+5% HP" над противником

### 5.4 Выход из режима иллюзии

- По истечению `durationMs` иллюзия сама спадает → бой продолжается нормально
- QTE-флаги сбрасываются для следующего цикла

## 6. Новая функция в useGame.ts

```ts
healBattle(fractionOfMax: number): void
// Увеличивает currentHP противника на fractionOfMax * maxHP
// Ограничивает: currentHP = min(currentHP + heal, maxHP)
```

## 10. Верификация

1. Запустить игру, дойти до Сектора 3 (или временно снизить стоимость разблокировки)
2. Начать бой с планетой 11 — иллюзия активируется через `intervalMs`
3. Дать QTE истечь или специально провалить → убедиться в +10% HP
4. После провала нажать несколько раз → каждый клик даёт +5% HP, HP не превышает максимум
5. Дождаться конца `durationMs` → иллюзия спадает, бой продолжается нормально
6. Успешно пройти QTE → иллюзия рассеивается, получить ×2 окно
7. Проверить: HP противника никогда не превышает `maxHP`
