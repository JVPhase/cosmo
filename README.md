# cosmo

## Сюжет

2387 год. Сектор 4, астероид B-119. Три часа назад добывающую станцию «Рассвет-6» атаковали пришельцы. Они ушли, оставив дыры в корпусе, выжженные реакторы и вас.

Резервы энергии почти на нуле: связь с “Министерством” недоступна из-за нехватки мощности передатчика. Чтобы выйти на контакт и подать запрос (в том числе на отпуск), нужно добрать достаточно `Энергиум™`.

Вам помогает напарник — КЛЕРК-7: выжил, работает на резервном питании и знает наизусть все страницы регламента. По регламенту любой шаг — это формы, заявки и “обязательные экземпляры”. Министерство (`МГММРДР`) хочет данных из реестра, а вы хотите выжить и пройти бюрократический коридор до связи.

По мере добычи `Энергиума™` вы развиваете производство: открываете новые планеты, вступаете в бой с охранниками, строите флот и крафтите пушки. Параллельно отправляете корабли в экспедиции — чтобы получать ресурсы и опыт, пока станция работает и «не устаёт».

## Жанр

**sci-fi idle clicker с атмосферой космической бюрократии.** Кликай, развивайся, захвати галактику — на досуге, между другими делами. Никакой стратегии флота — только Энергиум™ и регламент.

Добыча ресурсов через клики и автопоток, развитие технологий и кораблей, бои за планеты, экспедиции по таймеру.

## Суть геймплея

Вы работаете в “Межгалактическом Министерстве по Максимально Рациональной добыче Ресурсов” (МММРДР). Ваша задача — копить `Энергиум™`, открывать новые планеты, побеждать пришельцев на их территории и собирать металлы, необходимые для строительства флота и пушек.

Параллельно вы отправляете корабли в экспедиции, которые приносят добычу, опыт и ускоряют развитие.

## Быстрый старт (с примерами)

1. Добывайте `Энергиум™` на стартовой планете:
   - Игра стартует с планеты `1` (`Астероид Б-4`, `bonus = 1`).
   - На старте у вас нет апгрейдов, поэтому каждый `mineClick` даёт примерно `+1` энергии.
   - Пример: чтобы накопить `10_000` энергии для первой атаки, нужно около `10_000` кликов (пока не купили апгрейды).

2. Быстро откройте `АПГР.` и ускорьте добычу:
   - Вкладка `АПГР.` становится доступной, когда накоплено достаточно энергии (минимальная база среди апгрейдов — `50`).
   - Пример: сделайте около `50` кликов, купите `Лазерный бур Мк.1` (id `1`) и начните клики дальше — скорость энергии вырастет из-за `clickBonus`.

3. Соберите первый корабль:
   - Верфь (и строительство кораблей) требует металлы.
   - Первый корабль — `Разведчик «Нулевой»` — стоит `iron: 30`.
   - Металлы начинают появляться, когда `totalEarned` набирает порог (механически дроп включается, когда общая добыча уже достигла `>= 100`).

4. Атакуйте первую цель:
   - Чтобы начать бой с `Пламенниками` (планета `2`), нужна энергия в размере `ALIENS[].attackEnergyCost = 10_000`.
   - Важно: бой нельзя начать, если планета ещё не открыта или выбранный корабль сломан/в экспедиции — энергия списывается при старте.

5. После победы:
   - Планета становится открытой и автоматически выбирается.
   - Вы получаете `xpReward` за расу пришельцев и прогрессируете по требованиям, открывающим новые исследования/ветки.

## Вкладки и что там происходит

- `ДОБЫЧА`: клик/пассивная добыча, выбор активной планеты, быстрые подсказки.
- `АПГР.`: покупки улучшений для роста `clickPower` (клик) и/или `passiveRate` (энергия в секунду).
- `ПЛАН.`: просмотр охранников по планетам и старт боя (списывается `ALIENS[].attackEnergyCost`).
- `ВЕРФЬ`: строительство кораблей, крафт пушек, ремонт сломанных кораблей, запуск/забор экспедиций.
- `БОЙ`: таймер, HP противника, кнопка атаки и `✕ ОТСТУПИТЬ`.

## Роадмап прогресса (что качать и когда) — с примерами

Ранний этап (планета `1 -> 2`)

- Цель: как можно быстрее добраться до `10_000` энергии и провести первую победу.
- Что делать:
  - вначале качайте `APГР.` на клики (`clickBonus`) — это ускоряет набор энергии;
  - как только соберёте `iron`, стройте `Разведчик «Нулевой»`;
  - атакуйте планету `2`, чтобы открыть путь дальше.

Средний этап (открыть `3–5` и перейти к сектору `2`)

- Цель: собрать весь сектор `1` (планеты `1–5`), чтобы разблокировать сектор `2`.
- Что делать:
  - усиливайте урон пушек и/или корабельный множитель через более “тяжёлые” корабли;
  - в `RESEARCH` уделите внимание ветке `mining` — например, `mining_metal_1` добавляет `metalDropBonus`, повышая шанс дропа нужных металлов.

Поздний этап (сектор `2`, экспедиции, финальные охранники)

- Цель: максимизировать эффективность прогресса через экспедиции и урон в боях.
- Что делать:
  - после открытия сектора `2` награды экспедиций по металлам масштабируются `×5`;
  - в ветке `battle` берите узлы `battle_timer_*` и `battle_damage_*`, чтобы больше атак делать за один бой и быстрее “сносить” HP.

## Сохранения и сброс прогресса

- Игра сохраняет прогресс автоматически каждые `3` секунды.
- Состояние хранится в AsyncStorage под ключом `cosmo_game_v1` (версия `1`).
- “СБРОС ПРОГРЕССА” удаляет сохранение (`clearGame()` → удаление `cosmo_game_v1`) и возвращает `initial = {}`.
- Факт просмотра интро хранится отдельно: `cosmo_intro_seen_v1`.

## Сводка формул (коротко)

- Урон в бою за клик:
  - `damage = floor(computeBaseShipDamage(fleet) * damageResearchMultiplier)`,
  - `computeBaseShipDamage = floor((1 + cannonDamage) * ship.damageMultiplier)`,
  - `cannonDamage = sum(damagePerLevel * cannonLevel)` для выбранного корабля.
- Длительность боя: базовые `60_000 ms`.
- Дроп металлов:
  - шанс удачного ролла: `min(1, baseChance + metalDropBonus)`,
  - количество за удачный ролл: `max(1, floor(log10(max(1, planetBonus))))`,
  - `planetBonus` берётся из `planet.bonus`.
- Опыт `playerXP` растёт за клики и за события победы/экспедиций.

## Что делать после поражения

- По таймеру или при `✕ ОТСТУПИТЬ` корабль получает статус “сломано”.
- Дальше переходите в `ВЕРФЬ` и ремонтируете корабль за металлы (стоимость `repairCost`).
- После ремонта выбираете корабль и продолжаете цикл: добыча → металлы → пушки/корабли → атаки.

## FAQ по таймингу (с примерами)

1. “Когда атаковать?”
   - Атакуйте, когда у вас есть энергия на `ALIENS.attackEnergyCost` для нужной планеты и корабль не сломан.
   - Пример: планета `2` требует `10_000` энергии — до этого момента она остаётся недоступной.

2. “Как не просесть по металлам?”
   - Идите на планеты с более высокими `bonus` и/или повышайте `metalDropBonus` через исследования `mining`.
   - Пример: сначала `mining_click_1` / `mining_passive_1`, затем `mining_metal_1` — после этого дроп становится стабильнее.

3. “Как планировать экспедиции?”
   - Если корабль нужен в бою — не отправляйте его в миссию.
   - Пример: пока вы “копите” энергию и готовите следующий бой, отправьте другой корабль на `deep_space` на `2 часа`, чтобы получить награды к моменту возвращения.

## Механики

1. Добыча энергии:

   - `Энергиум™` накапливается от нажатий (активная добыча) и от пассивных улучшений (энергия в секунду).
   - У `totalEarned` есть порог: после достаточного накопления каждый клик начинает приносить дроп металлов.

2. Металлы и локации:

   - Дроп металлов зависит от выбранной планеты (таблица выпадения и шанс “за ролл”).
   - У каждой планеты есть `bonus` — множитель к доходности/эффективности добычи (влияет на мощность клика и частоту выпадений).

3. Сражения за планеты:

   - Вы выбираете планету и корабль во флоте.
   - Старт боя возможен, только если:
     - планета ещё не открыта,
     - выбранный корабль не сломан и не отправлен в экспедицию,
     - хватает `Энергиума™` на стоимость атаки `ALIENS[].attackEnergyCost` (энергия списывается при старте).
   - Параметры боя:
     - у противника `HP = alien.maxHP`,
     - длительность: базовые `60 секунд`.
   - Атаки:
     - на каждое нажатие атаки вы наносите `totalDamage/клик`,
     - `totalDamage` вычисляется от суммарного урона пушек (по уровням) и `damageResearchMultiplier` из исследований ветки `battle`.
   - Результаты:
     - победа: бой заканчивается, планета становится открытой и выбирается автоматически, игрок получает `xpReward` за расу пришельцев,
     - поражение (таймер истёк) или `✕ ОТСТУПИТЬ`: корабль ломается и требует ремонта металлами в Верфи.

4. Экосистема флота:

   - Металлы тратятся на строительство кораблей и на крафт пушек.
   - Пушки прокачиваются по уровням; их стоимость растёт, а урон увеличивается.
   - В бою урон корабля считается от суммарного урона пушек и множителя самого корабля, дополнительно усиливается исследованиями.
  
5. Технологии:

   - Есть два слоя развития: `апгрейды` и `исследования`.
   - Апгрейды стоят энергии и усиливают добычу (клик/пассив).
   - Исследования стоят энергии, открываются по уровню игрока и требуют предварительных узлов.

6. Экспедиции:

   - Корабль можно отправить на миссию на время (рейсы отличаются длительностью и наградами).
   - По завершении вы “забираете” награду: металлы и опыт.
   - После разблокировки “Дальнего Кластера” награды экспедиций масштабируются сильнее.

## Уровни игрока

Уровень игрока (`playerLevel`) вычисляется из общего опыта `playerXP`.

Откуда берётся `playerXP`:

- Активная добыча: каждый `mineClick` добавляет `+1` `playerXP`.
- Победа в бою: при уничтожении пришельца добавляется `xpReward` соответствующего расы.
- Экспедиции: при “забирании” экспедиции добавляется `xpReward` миссии.

Как считается `playerLevel`:

- Максимум: `MAX_LEVEL = 20`.

## Технологии

1. Апгрейды добычи (`UPGRADES`):
   - Апгрейды усиливают генерацию `Энергиума™`:
     - `clickBonus` увеличивает `baseClickPower` (сколько энергии приносит один клик).
     - `passiveBonus` увеличивает `basePassiveRate` (сколько энергии приходит в секунду).
   - Базовые формулы:
     - Стоимость апгрейда растёт по уровню: `floor(baseCost * 1.5^level)`.
     - Итоговый доход умножается на бонус текущей планеты (`planet.bonus`) и бонусы исследований (множители кликов/пассивной добычи).
   - Список апгрейдов (каждый апгрейд прокачивается уровнем) — `baseCost` показан как стоимость 1-го уровня:

  | id  | Апгрейд                           | Бонус за уровень   | Стоимость (ур.1) | Описание                                                                                        |
  | --- | --------------------------------- | ------------------ | ---------------- | ----------------------------------------------------------------------------------------------- |
  | 1   | ⚡ `Лазерный бур Мк.1`            | +1 `clickBonus`    | 50               | “Выдаётся бесплатно. Аккумулятор — за свой счёт. Зарядка — в нерабочее время.”                  |

2. Исследования (`RESEARCH`):
   - Исследования стоят `Энергиум™` и открываются по уровню игрока (`requiredLevel`), учитывая предшественников (`requires`).
   - Их эффекты суммируются:
     - `clickMultiplier` и `passiveMultiplier` добавляются к бонусам кликов/пассивной добычи (используются вместе с множителем планеты `planet.bonus`).
     - `metalDropBonus` добавляется к шансам выпадения металлов при дропе.
     - `damageMultiplier` усиливает урон в сражениях.
   - Полный список узлов (таблица):

## Telegram Mini App

Cosmo Miner работает как Telegram Mini App поверх того же клиента `mobile/cosmo-miner`.
Telegram — это runtime/build target + commerce-слой (Telegram Stars), а не отдельное приложение.

### Архитектура

```
mobile/cosmo-miner/
  src/telegram/
    runtime.ts   — isTelegramRuntime(), bootstrapTelegram()
    auth.ts      — telegramAuthIfNeeded() — POST /telegram/auth → JWT
    StarsShopTab.tsx — вкладка Stars в ShopScreen
```

- Native (iOS/Android) — Telegram-адаптер отключён через Platform.OS guards, ничего не ломается.
- Web build (`expo export --platform web`) — Telegram Mini App runtime активен.

### Запуск web build

```bash
cd mobile/cosmo-miner
npx expo export --platform web   # или: npx expo start --web
```

Артефакт сборки появляется в `mobile/cosmo-miner/dist/`.
Разместите его на HTTPS-хосте (Vercel, Netlify, nginx и т.п.).

### Env vars

| Переменная | Где | Назначение |
|---|---|---|
| `EXPO_PUBLIC_API_URL` | mobile/.env | URL сервера, например `https://api.example.com` |
| `TELEGRAM_BOT_TOKEN` | server/.env | Токен бота из BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | server/.env | Секрет для верификации Telegram webhook |
| `DATABASE_URL` | server/.env | PostgreSQL connection string |

### Checklist: переключение BotFather URL (ручные шаги)

1. Откройте @BotFather в Telegram.
2. `/mybots` → выберите своего бота → **Bot Settings** → **Menu Button** (или **Configure Mini App**).
3. Установите Web App URL = URL вашего `expo web` build, например:
   `https://cosmo-miner.vercel.app`
4. Сохраните.
5. Для webhook: убедитесь, что зарегистрирован webhook на `/telegram/webhook` вашего сервера:
   ```
   POST https://api.telegram.org/bot<TOKEN>/setWebhook
   {
     "url": "https://api.example.com/telegram/webhook",
     "secret_token": "<TELEGRAM_WEBHOOK_SECRET>"
   }
   ```
6. Откройте бота → **Menu** (или кнопка запуска Mini App) — должен открыться web build.
