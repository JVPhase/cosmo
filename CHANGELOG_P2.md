## Что было сделано

### 1. Механика щита (QTE)

**Файл:** `mobile/cosmo-miner/src/screens/BattleScreen.tsx`

Пришельцы с способностью `shield` периодически активируют щит. В момент активации:

- За 2 секунды до щита корабль врага начинает мигать с ускоряющейся анимацией (медленно → быстро → турбо)
- При активации щита атаки заблокированы (`effectiveDamage = 0`)
- Поверх врага появляется кольцо QTE (`SkillCheckRing`) с рандомной зоной попадания
- Граница круга меняет цвет с красного на синий
- Подсказка меняется на `🎯 НАЖМИТЕ В КРАСНУЮ ЗОНУ!`

**Успешный QTE** — щит снимается досрочно, открывается **окно возможностей ×2** на время, равное оставшейся длительности щита. В шапке появляется `⚡ ×2 АТАКА!`.

**Провал QTE** — штраф **−2 с** к таймеру боя. Последующие клики по активному щиту наносят **×0.5 урона** и стоят **−1 с** каждый.

Таймеры щита реализованы через самоперезапускающийся `setTimeout` (фаза idle `intervalMs` → фаза active `durationMs` → повтор). Корректно очищаются при завершении боя.

### 3. Расчёт урона

Текущий эффективный урон отображается в строке статистики (шапка экрана):

```
effectiveDamage = abilityActive ? 0 : floor(totalDamage × attackMultiplier)
attackMultiplier = opportunityActive ? 2 : 1
```

Примеры:
- Обычная атака: `×1.0`
- Щит активен: `×0` (атака заблокирована)
- Окно возможностей (после успешного QTE): `×2.0`
- Провал QTE, клик по щиту: `×0.5` и −1 с к таймеру

### 4. Системные изменения

**`useGame.ts`** — `attackBattle` теперь принимает опциональный параметр `multiplier: number = 1`, который применяется к расчёту урона:
```typescript
const damage = Math.floor(
  computeBaseShipDamage(prev.fleet) * derived.damageResearchMultiplier * multiplier
);
```

Привязка в `App.tsx` (`onAttack={game.attackBattle}`) не потребовала изменений — сигнатура обратно совместима.

## Критерий из роадмапа

> Игрок, который пришёл к бою, делает осознанные решения, а не просто спамит кнопку.

Реализовано: игрок должен следить за предупреждением (мигание корабля), попасть в QTE-зону чтобы снять щит досрочно и получить ×2 бонус, либо принять штраф −2 с за провал. Игнорирование щита полностью блокирует урон на время его действия.
