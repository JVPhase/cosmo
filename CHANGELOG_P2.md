## Что было сделано

### 1. Механика уязвимости (timing window)

**Файл:** `mobile/cosmo-miner/src/screens/BattleScreen.tsx`

Каждые 4 секунды враг "открывается" на 1.5 секунды. В этот момент:

- Вокруг врага появляется золотое пульсирующее кольцо (анимация `Animated.loop`)
- В области врага появляется бейдж **"⚡ УЯЗВИМ ×3"**
- Подсказка внизу экрана меняется с `◈ ЖМИТЕ ДЛЯ АТАКИ ◈` на `⚡ УЯЗВИМ — АТАКУЙТЕ! ⚡`
- Граница круга меняет цвет с красного на золотой
- Атака в этот момент наносит **×3 урона**

Таймер реализован через самоперезапускающийся `setTimeout` (фаза closed 4000 мс → фаза open 1500 мс → повтор). Корректно очищается при завершении боя.

### 2. Комбо-счётчик

**Файл:** `mobile/cosmo-miner/src/screens/BattleScreen.tsx`

- Каждая атака **во время окна уязвимости** увеличивает счётчик комбо (0 → 1 → 2 → 3)
- Атака **вне окна** сбрасывает счётчик в 0
- При достижении 3 — активируется **комбо-бонус ×1.5** на следующую атаку (любую)
- После использования бонус сбрасывается

Визуальная обратная связь в строке статистики (шапка экрана):
- `⚡ 2/3` — текущий прогресс комбо (оранжевый)
- `✨ +50%` — бонус готов (золотой)

### 3. Уникальные способности пришельцев

**Файл:** `mobile/cosmo-miner/src/game/ALIENS.ts`

Добавлен тип `AlienAbility` с двумя вариантами:

```typescript
type AlienAbility =
  | { type: 'shield'; intervalMs: number; durationMs: number; damageMultiplier: number }
  | { type: 'blur';   intervalMs: number; durationMs: number; damageMultiplier: number }
```

Способности назначены двум расам:

| Раса | Планета | Способность | Цикл | Эффект |
|---|---|---|---|---|
| Кристаллиты | 3 | `shield` | каждые 15 с, активна 3 с | атаки в щите — ×0.5 урона |
| Туманники | 4 | `blur` | каждые 8 с, активна 2 с | атаки при размытии — ×0.5 урона |

Визуальная обратная связь:
- **Shield:** синяя рамка вокруг врага + бейдж `🛡 ЩИТОВАН ×0.5`
- **Blur:** изображение корабля становится прозрачным (opacity 0.35) + бейдж `👻 РАЗМЫТ ×0.5`

### 4. Стекование множителей

Все три множителя перемножаются:

```
итоговый_урон = базовый_урон × окно_уязвимости × способность × комбо_бонус
```

Примеры:
- Обычная атака: `×1.0`
- Во время окна: `×3.0`
- Во время окна + щит Кристаллитов: `×1.5`
- Во время окна + комбо-бонус: `×4.5`
- Обычная атака + комбо-бонус: `×1.5`

Текущий эффективный урон отображается в шапке рядом с базовым значением (цвет: золотой при бонусе, красный при штрафе).

### 5. Системные изменения

**`useGame.ts`** — `attackBattle` теперь принимает опциональный параметр `multiplier: number = 1`, который применяется к расчёту урона:
```typescript
const damage = Math.floor(
  computeBaseShipDamage(prev.fleet) * derived.damageResearchMultiplier * multiplier
);
```

Привязка в `App.tsx` (`onAttack={game.attackBattle}`) не потребовала изменений — сигнатура обратно совместима.

## Критерий из роадмапа

> Игрок, который пришёл к бою, делает осознанные решения, а не просто спамит кнопку.

Реализовано: игрок должен отслеживать окно уязвимости (×3), следить за способностью врага (Кристаллиты — ждать, пока упадёт щит; Туманники — не тратить комбо во время размытия) и строить комбо для бонусной атаки.
