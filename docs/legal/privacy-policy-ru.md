## 2. Какие данные мы собираем

### 2.1 Данные профиля Telegram
При запуске Cosmo через Telegram платформа передаёт нам следующие данные из вашего профиля:
- Числовой ID Telegram
- Имя, фамилия (если указаны)
- Имя пользователя (username, если указано)
- URL фотографии профиля (если установлена)
- Код языка интерфейса
- Статус Telegram Premium

Данные передаются через подписанный payload `initData` и верифицируются на сервере через HMAC-SHA256.

### 2.2 Данные учётной записи (необязательно)
При регистрации через email и пароль:
- Адрес электронной почты
- Пароль (хранится в виде необратимого хеша Argon2 — мы не имеем доступа к паролю в открытом виде)

При входе через Google или Apple:
- ID пользователя у провайдера и наименование провайдера

### 2.3 Игровые данные
- Игровое состояние (ресурсы, здания, флот, исследования) в формате JSON
- Баланс игрового кошелька (авторитативные кредиты на сервере)
- Инвентарь (приобретённые предметы, бустеры, скины)
- История покупок (предмет, сумма в Telegram Stars, ID платёжной транзакции, дата)

### 2.4 Технические данные
- IP-адрес и User-Agent браузера — фиксируются в серверных логах для обеспечения безопасности

Мы **не собираем** данные банковских карт, точную геолокацию и биометрические данные.

## 9. Меры защиты данных

Мы применяем:
- Хеширование паролей по алгоритму Argon2
- HMAC-SHA256 верификацию Telegram-авторизации
- JWT-токены с механизмом ротации refresh-токенов
- HTTPS для всех соединений
- Rate limiting на всех эндпоинтах
